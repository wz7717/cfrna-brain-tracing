# BrainTrace public synthetic examples

These files provide deterministic, public smoke-test inputs for the locked
BrainTrace three-tier production route.

> **This example is a synthetic software smoke-test input. It is not a
> biological sample and must not be used to assess biological or localization
> performance.**

The values were generated deterministically from public gene identifiers in
the packaged frozen model. They do not come from a donor, patient, tissue,
disease cohort, or from the restricted Bo2023 processed author-package
matrices. The examples are intentionally not designed to produce a particular
anatomical answer.

## Files

- `braintrace_example_counts.tsv`: `gene_symbol` plus deterministic positive
  integer `raw_counts`.
- `braintrace_example_logcpm.tsv`: the same public gene identifiers plus
  deterministic synthetic `logCPM` values.
- `expected_output_counts.json` and `expected_output_logcpm.json`: outputs
  generated by the locked production route, not hand-edited predictions.
- `verify_examples.py`: verifies both examples against the committed outputs,
  model lock, overlap gates and packaged public artifacts.

## Run

```bash
braintrace validate
braintrace query \
  --input examples/braintrace_example_counts.tsv \
  --output example_result.json
python examples/verify_examples.py
```

Both examples must satisfy the public production gates: at least 100 of the
locked 200 Network genes and at least 20 regional-reference genes. Network
Top3 is the primary validated candidate tier, Resolution Group Top3 is the
recommended resolvable tier, and Exact-Region Top3 is exploratory only.
